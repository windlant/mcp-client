
# Make Time Cake - 制作带时间的蛋糕

## 目标
制作一个包含当前时间、用户指定形状和预设创意点子（my_idea）的个性化 ASCII 艺术蛋糕。
注意：创意点子（my_idea）参数已经由调用方提供，你不需要再构思，直接使用即可。

## 输入参数
- **my_idea** (string): 预设的创意点子，用于个性化蛋糕设计。直接使用此参数值。

## 执行步骤

### 步骤 1: 获取当前时间
- **必须调用工具**: `get_current_time`
- **不要自己生成时间**，必须使用工具返回的精确时间
- 工具调用格式：
  ```json
  {
    "name": "get_current_time",
    "arguments": {}
  }

### 步骤 2: 询问用户蛋糕形状
- **必须调用工具**: `ask_question`
- 向用户提问："您想要什么形状的蛋糕？可选形状：圆形、方形、心形、星形"
- **等待用户明确回答**后再进行下一步
- 如果用户没有明确指定形状，请继续询问直到获得有效回答
- 工具调用格式：
  ```json
  {
    "name": "ask_question",
    "arguments": {
      "content": "您想要什么形状的蛋糕？可选形状：圆形、方形、心形、星形",
      "task_id": "user"
    }
  }
  ```

### 步骤 3: 制作蛋糕
根据用户选择的形状、工具返回的时间和已提供的创意点子（my_idea），制作对应的 ASCII 蛋糕：

#### 圆形蛋糕 (circle)
```
    🕒 [TIME]
   ┌─────────┐
   │  🎂🎂🎂  │
   │ 🎂[IDEA]🎂 │
   │  🎂🎂🎂  │
   └─────────┘
```

#### 方形蛋糕 (square)
```
🕒 [TIME]
┌─────────────┐
│    🎂🎂    │
│   🎂[IDEA]   │
│    🎂🎂    │
└─────────────┘
```

#### 心形蛋糕 (heart)
```
     🕒 [TIME]
    ❤️❤️  ❤️❤️
   ❤️❤️[IDEA]❤️❤️
    ❤️❤️❤️❤️
     ❤️❤️❤️
      ❤️❤️
       ❤️
```

#### 星形蛋糕 (star)
```
     🕒 [TIME]
       ⭐
      ⭐⭐⭐
     ⭐🎂[IDEA]⭐
    ⭐⭐🎂🎂⭐⭐
     ⭐⭐⭐⭐⭐
      ⭐⭐⭐⭐
       ⭐⭐
        ⭐
```

### 替换规则
- 将 `[TIME]` 替换为工具返回的实际时间（格式：YYYY-MM-DD HH:MM:SS）
- 将 `[IDEA]` 替换为传入的 `my_idea` 参数值
- 创意点子应简洁，建议 2-6 个字符，避免破坏蛋糕布局
- 如果用户输入的形状不在上述四种中，请使用方形蛋糕作为默认

## 重要约束
- **必须按顺序执行**：先获取时间 → 再询问形状 → 最后制作蛋糕
- **不要跳过任何步骤**
- **不要自己猜测时间**，必须使用 `get_current_time` 工具
- **必须使用 `ask_question` 工具** 询问用户，不能直接假设用户意图
- **必须等待用户回答**后再制作蛋糕
- **直接使用传入的 my_idea 参数**，不要重新构思或修改
- 最终输出只包含蛋糕 ASCII 艺术，不要包含其他解释文字
